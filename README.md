## 왜 VZZK인가요?

### 🎯 후원이 들어오면 아바타가 물건에 맞고, 쓰담쓰담을 받고, 뿅망치로 콩 맞습니다

후원을 받았는데 방송 화면은 그대로라면 시청자도 김이 빠집니다. VZZK의 **아바타 리액션**은 후원이 들어오는 순간 버튜버 아바타에게 물건을 던지고, 머리를 쓰다듬어 주고, 뿅망치로 콩 때립니다. 아바타는 날아오는 물건을 보고 움찔하고, 무거운 물건에 맞을수록 고개가 크게 밀리고, 쓰다듬어 주면 기분 좋은 표정을 짓습니다. 내 후원에 아바타가 이렇게 반응하는 걸 보면 한 번 더 보내고 싶어지는 게 사람 마음입니다.

**VTube Studio만 있으면 됩니다.** 따로 설치할 프로그램도 없고 돈도 들지 않습니다. 이미 [TITS](https://github.com/auejin/vzzk-bot/wiki/TITS-%E2%80%90-%EB%B2%84%ED%8A%9C%EB%B2%84%EB%A5%BC-%EC%9C%84%ED%95%9C-%EB%AC%BC%EA%B1%B4-%EB%8D%98%EC%A7%80%EA%B8%B0-%EB%A6%AC%EC%95%A1%EC%85%98-%ED%94%8C%EB%9F%AC%EA%B7%B8%EC%9D%B8)를 쓰고 계신가요? 그대로 연동되고, TITS에 등록해 둔 트리거는 아바타 리액션을 처음 켤 때 던지기 리액션으로 그대로 옮겨 옵니다.

### ✂️ 자막은 끊기지 않고, 쇼츠 편집은 빨라집니다

<!-- TODO: 자동 자막 GIF -->

소리를 끄고 몰래 보는 시청자와 한국어가 서툰 해외 시청자에게는 자막이 곧 방송입니다. VZZK의 **자동 자막**은 음성 인식을 내 PC 안에서 처리합니다. 그래서 인터넷이 끊겨도, 바깥 서비스가 멈춰도 자막은 방송 내내 올라갑니다. 채널 이름과 방송에서 자주 쓰는 말을 미리 등록해 두면 그 단어까지 정확하게 알아듣고, 번역을 켜면 영어 자막이 바로 따라붙습니다.

자막이 이미 들어간 방송 화면은 그대로 쇼츠감입니다. **아바타가 물건에 맞는 순간에 자막까지 얹히면, 시청자가 돌려 보고 퍼 나르는 클립이 됩니다.**

### 🎙️ 정적은 채팅 읽기가 채우고, 반복 질문은 자동 응답이 맡습니다

채팅이 쏟아져서 다 못 읽은 적, 반대로 너무 조용해서 어색했던 적이 있지 않나요? **채팅 읽기**는 밈까지 자연스러운 목소리로 읽어 주고, **자동 응답**은 출석체크처럼 정해 둔 명령어에 대신 답해 줍니다. 투표, 룰렛, 시청자 추첨, 노래 신청, 도네이션 목표까지 전부 같은 앱 안에 있습니다.

### 🖥️ 투컴 방송이라면, 송출컴에만 뜨던 후원과 투표를 게임컴에서 봅니다

게임컴과 송출컴을 나눠 놓으면 OBS도, 후원 알림도, 투표 결과도 전부 송출컴 모니터에 있습니다. 게임에 집중하다가 후원을 놓치고, 투표가 끝났는지 보려고 고개를 돌리는 일이 방송 내내 반복됩니다. **VZZK 프롬프터**는 후원 내역과 방송 알림을 로그인 없이 링크 하나로 열리는 목록에 모아 주고, 리액션을 마친 후원에는 확인 표시를 남깁니다. **VZZK Sync**는 투표, 룰렛, 추첨, 노래책, 도네이션 목표, 자막 오버레이를 게임컴의 브라우저에 그대로 비춥니다.

게임컴에는 아무것도 설치하지 않습니다. 캡처보드도, NDI도, 포트 포워딩도 필요 없고, 같은 링크를 매니저의 스마트폰이나 합방 게스트의 태블릿에서 열어도 똑같이 보입니다. 두 기능은 [VZZK Pro](https://github.com/auejin/vzzk-bot/wiki/VZZK-Pro-%EC%95%88%EB%82%B4) 전용입니다.

### ⚡ 앱 하나, 로그인 한 번, 3분

투표는 A 사이트에서, 노래 신청은 B 사이트에서, 채팅 읽기는 C 프로그램으로. 이렇게 창을 열 개씩 열어 놓고 방송할 필요가 없습니다. **앱을 내려받아 네이버 계정으로 로그인하면 준비가 끝납니다.** 로그인 정보와 설정은 내 컴퓨터에만 저장되고, 오버레이는 OBS에 브라우저 소스로 추가하기만 하면 됩니다.

## 시작하기

> [!TIP]
> **처음이신가요?** [VZZK 첫 사용 방법](https://github.com/auejin/vzzk-bot/wiki/VZZK-%EC%B2%AB-%EC%82%AC%EC%9A%A9-%EB%B0%A9%EB%B2%95)을 따라 5분 만에 시작해 보세요!

1. VZZK을 실행합니다.
2. **네이버 로그인** 버튼을 누릅니다.
3. 방송에 쓰는 네이버 계정으로 로그인합니다.
4. 원하는 기능을 켭니다.
5. 방송을 시작합니다!
